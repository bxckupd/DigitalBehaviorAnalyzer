# DigitalBehaviorAnalyzer

## О проекте

Этот проект анализирует цифровые привычки пользователя на основе данных об использовании телефона.

В проекте анализируются:
экранное время
сон
продуктивность
настроение
использование приложений

Данные генерируются автоматически и близки к реальным.

## Что может делать программа

Программа может:
показывать среднее время, проведенное за экраном
анализировать время сна
сравнивать дни недели и выходные
находить связь между временем, проведенным за экраном, и производительностью
показывать дни наибольшего использования телефона


## Используемые библиотеки
pandas
numpy
matplotlib
pytest

## Как пользоваться 
Генерация данных:
python data_generator.py
Общая статисттика:
python main.py stats
Анализ выходных:
python main.py weekend
Корреляция:
python main.py correlation
Дни с большим экранным временем:
python main.py toxic
Запуск всех режимов и выведение полных данных:
Полный анализ:
python main.py full
